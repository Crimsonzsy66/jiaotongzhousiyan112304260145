# 第四次实验报告：交通标志检测

## 一、实验目的
使用YOLOv8模型进行交通标志目标检测，实现高精度的交通标志识别与定位，并对训练代码进行优化重构，提升训练效率和代码可维护性。

## 二、实验环境
- 硬件：NVIDIA GeForce RTX 4060 Laptop GPU
- 软件：Python 3.12，PyTorch，Ultralytics YOLOv8
- 数据集：交通标志检测数据集（YOLO格式）

## 三、实验方法

### 3.1 数据准备
- 数据集采用标准YOLO格式
- 包含15个类别：
  0. 绿灯
  1. 红灯
  2. 限速10
  3. 限速100
  4. 限速110
  5. 限速120
  6. 限速20
  7. 限速30
  8. 限速40
  9. 限速50
  10. 限速60
  11. 限速70
  12. 限速80
  13. 限速90
  14. 停止标志

### 3.2 模型选择
使用YOLOv8s（small版本）作为基础模型，相比nano版本具有更高的检测精度和更好的性能。

### 3.3 训练配置
- 预训练模型：YOLOv8s
- 训练轮数：100 epochs
- 图像尺寸：640x640
- 优化器：SGD
- 学习率：0.01（初始），0.01（最终）
- 动量：0.937
- 权重衰减：0.0005
- 早停机制：patience=50
- 数据增强：Mosaic、MixUp、CopyPaste等
- 启用混合精度训练（AMP）

### 3.4 代码优化
对训练脚本进行了全面的优化重构：
- **模块化设计**：将代码拆分为独立的函数（setup_paths、load_model、get_train_config、train_model、evaluate_model）
- **路径管理优化**：使用pathlib.Path动态获取相对路径，移除硬编码路径
- **参数精简**：删除35+个冗余默认参数，训练参数从99个减少到36个核心参数
- **性能优化**：workers从0提升到4，启用cache=True加速训练
- **日志系统**：使用logging模块替代print，添加时间戳和结构化输出
- **错误处理**：添加try-except块捕获训练和评估中的错误

## 四、实验结果

### 4.1 训练过程
训练在RTX 4060 Laptop GPU上进行，采用以下优化策略：
- 使用YOLOv8s预训练模型
- 启用早停机制避免过拟合
- 启用数据增强提升泛化能力
- 启用混合精度训练加速

### 4.2 性能指标

| 指标 | 数值 |
|------|------|
| mAP@0.5 | 94.43% |
| mAP@0.5-0.95 | 81.23% |
| Precision | 94.84% |
| Recall | 87.81% |

### 4.3 训练曲线
- 训练损失持续下降，表明模型学习有效
- 验证mAP持续提升，在最佳epoch达到最佳性能
- 启用早停机制，有效防止过拟合
- 使用余弦学习率调度器，训练过程更加稳定

### 4.4 代码优化效果
- **可维护性提升**：代码结构清晰，模块化设计易于维护和扩展
- **训练效率提升**：启用cache和优化workers数量，加快数据加载
- **调试便捷性**：完善的日志系统和错误处理，便于问题追踪
- **代码简洁性**：删除冗余参数，核心参数一目了然

## 五、实验分析

### 5.1 模型优势
1. 检测精度高，mAP@0.5达到94.43%
2. 模型收敛快，训练效率高
3. 使用GPU加速，推理速度快
4. 代码结构优化，便于后续维护和迭代

### 5.2 改进方向
1. 可以尝试使用更大的模型（如YOLOv8m/l）来进一步提升精度
2. 可以尝试更高级的数据增强策略提升模型泛化能力
3. 可以调整置信度阈值来优化检测效果
4. 可以添加模型集成策略进一步提升性能
